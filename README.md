# 🧠 Code With AI Quiz

An interactive quiz application designed to test and improve knowledge of Artificial Intelligence, Large Language Models (LLMs), and modern AI concepts.

🌐 **Live Demo:** [Play Code With AI Quiz](https://quiz-delta-cyan-39.vercel.app/)

## 📌 About the Project

Code With AI Quiz is a web-based quiz application that helps users explore and test their understanding of Artificial Intelligence through interactive multiple-choice questions.

The project focuses on making AI learning simple, engaging, and accessible through a clean and user-friendly interface.

## ✨ Features

- 🧠 **AI Knowledge Questions:** Test your understanding of Artificial Intelligence and Large Language Models.
- 📝 **Multiple-Choice Questions:** Answer questions by selecting from available options.
- ⚡ **Interactive Interface:** Simple and engaging quiz experience.
- 📱 **Responsive Design:** Accessible across desktop, tablet, and mobile devices.
- 🎯 **Learning Through Practice:** Improve your understanding of modern AI concepts.
- 🎨 **Clean UI:** Easy-to-use interface designed for a smooth experience.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- A modern web browser
- Git
- Visual Studio Code (recommended)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/mrinalsaini7/Quiz.git
```

**2. Navigate to the project folder**

```bash
cd Quiz
```

**3. Open the project**

Open `index.html` in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.

## 🎮 How to Use

1. Open the quiz application.
2. Read the displayed AI-related question.
3. Select your preferred answer from the available options.
4. Continue exploring the quiz questions.
5. Test your knowledge of AI and LLM concepts.
